# Configuração de Login Social - Startup Enxuta

## 🎯 Objetivo
Login com Google zero custo, usando localStorage temporário + Supabase.

## 📋 Pré-requisitos

### 1. Google OAuth
- Vá para: https://console.cloud.google.com/apis/credentials
- Crie "OAuth 2.0 Client IDs"
- Configure "Authorized redirect URIs": `http://localhost:3000/auth/callback`
- Copie Client ID e Client Secret

### 2. Supabase
- Crie projeto em: https://supabase.com
- Crie tabela `users`:
```sql
CREATE TABLE users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  email VARCHAR(255) UNIQUE NOT NULL,
  name VARCHAR(255),
  avatar_url TEXT,
  provider VARCHAR(50) DEFAULT 'google',
  provider_id VARCHAR(255) UNIQUE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  last_login TIMESTAMPTZ
);
```
- Copie URL e Service Role Key

## 🔧 Configuração

1. Copie `.env.local.example` → `.env.local`
2. Preencha suas credenciais:
```env
NEXT_PUBLIC_GOOGLE_CLIENT_ID=seu-client-id
GOOGLE_CLIENT_SECRET=seu-client-secret
NEXT_PUBLIC_REDIRECT_URI=http://localhost:3000/auth/callback
NEXT_PUBLIC_SUPABASE_URL=seu-supabase-url
SUPABASE_SERVICE_ROLE_KEY=seu-service-role-key
```

## 🚀 Como Funciona

1. **Click Login Google** → Abre popup OAuth
2. **Google Responde** → Armazena código no localStorage (60 segundos)
3. **API Processa** → Envia código para Google, troca por token
4. **Supabase Cria** → Salva usuário com dados do Google
5. **Limpa Tudo** → localStorage limpo automaticamente

## 🔒 Segurança Implementada

- Dados expiram em 60 segundos
- Limpeza automática em múltiplos pontos
- Storage temporário apenas durante flow
- Validação de timestamp

## 📱 Fluxo do Usuário

1. Entrar em `/login`
2. Clicar "Continuar com Google"
3. Autorizar no popup (uma vez)
4. Redirecionado automaticamente pro dashboard

## 💰 Custo

- **Zero adicional** - usa apenas Google OAuth + Supabase
- **Sem backend extra** - roda em serverless Next.js
- **Infra enxuta** - mínimo necessário funcionando

## 🐛 Troubleshooting

- **ERRO redirect_uri**: Verifique se URL bate exato no Google Console
- **ERRO token**: Verifique Client Secret correto
- **ERRO Supabase**: Verifique Service Role Key (não o anon key)

## 🚀 Produção

Altere em produção:
```env
NEXT_PUBLIC_REDIRECT_URI=https://seusite.com/auth/callback
```

E atualize authorized redirect URIs no Google Console.
